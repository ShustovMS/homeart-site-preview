# HOMEART — рабочая версия сайта (MVP к запуску)

Копия прототипа `prototype-v1` от 12.10.2026, из которой собирается боевой homeart.pro.
Референс «как задумывали» — `сайт_портал/prototype/` (не меняется).

План, решения и график: `сайт_портал/ПЛАН_запуска_MVP.md`.
Локальный просмотр: http://localhost:5622 (конфигурация `site` в `.claude/launch.json`).

## Публичные адреса разделов

Маршруты основных страниц и категорий заданы в `../_build/clean_urls.py`.
Исходники страниц находятся в корне `site/`. После сборки и проверки карточек из базы обновите готовый HTML базовым сборщиком `product_seo.cjs` на локальном сервере, как в инструкции каталога. Затем соберите чистые
страницы из актуальных исходников и данных каталога, затем карту и редиректы.

```sh
python сайт_портал/_build/clean_pages.py
python сайт_портал/_build/sitemap.py
python сайт_портал/_build/redirects.py
```

После обновления данных каталога пересоберите страницы категорий, чтобы HTML
для посетителей без JavaScript и ссылки для роботов соответствовали ассортименту.
После изменений в `kitchen.html` пересоберите `kitchen/index.html`. Публичные
страницы кухонных брендов и коллекций находятся под `/kitchen/<бренд>/…`.
Сборщик берёт их из реестров Molteni, TM Italia и Castagna Cucine. При добавлении
Castagna внесите её исходники и реестр, затем выполните те же три команды.

### Когда добавляется карточка, проект или дизайнер

- Сохраняйте ID уже опубликованной записи при смене названия. Постоянные URL
  хранятся в `../_build/entity-urls.json`. Сборщик добавляет новые записи, а
  ранее назначенные пути использует снова.
- Сборщик выпускает адреса товаров под `/catalog/<категория>/`, проектов под
  `/projects/` и дизайнеров под `/projects/designers/`. Внутренние ссылки
  используют сгенерированный `data/page-urls.js`. Адреса и редиректы вручную
  вписывать в sitemap или Caddy не требуется.
- Перед выкладкой проверьте открытие новой страницы, совпадение canonical
  с sitemap и переход со старого URL. Сборку и манифест сверяйте со свежим
  main, чтобы сохранить опубликованные параллельно записи и маршруты.
